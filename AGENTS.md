# AGENTS.md

Entry point for AI agents and new contributors working on `moviepy.ae`, the After Effects-style
compositing package in this fork. Setup, test and first render take about five minutes.

## Setup

```console
git clone <this repository>
cd moviepy
python -m venv .venv
pip install -e ".[test,lint]"
pip install -e ".[svg]"      # optional: editable SVG layers (resvg-py, fonttools)
```

Python 3.9 or newer. FFmpeg is found through `imageio-ffmpeg` unless you set `FFMPEG_BINARY`.
On Windows set `PYTHONUTF8=1` before running tests, because docs and test names contain non-ASCII text.
The extras are declared in [pyproject.toml](pyproject.toml): `svg`, `doc`, `test`, `lint`.

## Test and lint (exact commands)

```console
pytest tests/ae -q -p no:cacheprovider      # the ae suite
pytest tests -q                              # whole suite: existing moviepy tests must stay green
pytest tests/ae/test_repo_guides.py -q       # checks the links and the README quickstart
black --check <files>
isort --check-only <files>
flake8 <files>
```

Run lint on the files you touched. Conventional Commits are required, for example `feat(ae): ...`
or `docs(ae): ...`.

## Package map of moviepy/ae

| Path | What it holds |
|---|---|
| `moviepy/ae/__init__.py` | Lazy public exports (`Composition`, `BlendMode`, `write_master`, ...) |
| `moviepy/ae/buffer.py`, `moviepy/ae/context.py` | `Buffer` (float RGB plus mask) and `RenderContext` (time, fps, seed) |
| `moviepy/ae/composition.py`, `moviepy/ae/renderer.py` | `Composition` and the frame renderer |
| `moviepy/ae/master.py` | `write_master` for linear and 16-bit masters |
| `moviepy/ae/layers/` | Solid, AV, comp, null, adjustment and SVG layers |
| `moviepy/ae/properties/` | `Property`, keyframes, easing, expressions |
| `moviepy/ae/blend/` | Blend modes and alpha modes |
| `moviepy/ae/masks/` | Masks and track mattes |
| `moviepy/ae/effects/` | Effect base, stack, registry and the effect families (blur, color, distort, generate, noise, perspective, stylize, time, transition) |
| `moviepy/ae/time/` | Time remap, frame blending, motion blur |
| `moviepy/ae/text/`, `moviepy/ae/particles/`, `moviepy/ae/three_d/`, `moviepy/ae/svg/` | Text, particle, 3D camera and SVG support |
| `moviepy/ae/audio/` | Layer audio mixing |
| `moviepy/ae/motion/` | Motion-graphics specs, captions, transitions |
| `moviepy/ae/templates/` | Video pipelines and the `python -m moviepy.ae.templates` CLI |
| `tests/ae/` | Tests, synthetic assets and golden images |

## Conventions (from docs/AE_PARITY_SPEC.md section 9)

Read [docs/AE_PARITY_SPEC.md](docs/AE_PARITY_SPEC.md) for the full text. The short form:

- Public API has a numpydoc docstring and at least one runnable example.
- Parameters that can animate are `Property` values and have a keyframe test.
- Rendering is deterministic: same input gives identical bytes. Randomness goes through `ctx.rng_seed`, never global `np.random`.
- No hard-coded paths or secrets, no `print` or debug leftovers, no swallowed exceptions. Validate inputs and give clear error messages.
- New dependencies follow spec section 3.6 and need a clear error when missing.
- Files stay at or under 800 lines, functions under 50 lines.
- Test assets are synthetic or self-made and live in `tests/ae/assets/`. Golden images are generated by code.
- Existing moviepy code changes only through the hooks listed in spec section 9.4.
- Update the docs and CHANGELOG with the change.

## Never invent or substitute human-supplied media

Music, video clips, images, narration, subtitles, titles and fonts for a real episode come from a
human. Do not generate, download, synthesize or swap in placeholders for them, and do not silently
fall back to a different file. If an input is missing, stop and report which file is missing.
Synthetic media is allowed only inside tests under `tests/ae/`. Nothing is uploaded or published;
human gates (listening, watching, rights, upload) are reported as `NOT_RUN`.

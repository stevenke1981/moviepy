# moviepy.ae documentation index

`moviepy.ae` adds After Effects-style compositing to MoviePy: layers, keyframed properties, blend
modes, masks, effects, time controls and templates for finished videos. Start with the quickstart in
the [repository README](../../README.md), then pick a group below. The design is in
[AE_PARITY_SPEC.md](../AE_PARITY_SPEC.md).
